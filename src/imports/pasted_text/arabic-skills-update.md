1. QIRĀ'AH — READING
   ==================================================

Add a Reading activity inside the Meaningful Learning section.

After students learn the vocabulary, provide a short Arabic text or dialogue related to the learning topic.

Use age-appropriate Arabic for Grade 7 students.

For example, if the topic is "الأيام":

Create a short dialogue between two students discussing their weekly activities and school schedule.

Example structure:

Student A:
"ماذا تفعل يوم الاثنين؟"

Student B:
"أذهب إلى المدرسة وأدرس اللغة العربية."

Student A:
"وماذا تفعل يوم الجمعة؟"

Student B:
"أذهب إلى المسجد وأرتاح مع أسرتي."

Do not make the text too long.

Provide:

* Arabic text
* Optional Indonesian translation
* Highlight important vocabulary
* Play audio button
* Read-aloud interaction
* Comprehension questions after reading

Add a "Baca dan Pahami" label.

The reading activity should assess:

* understanding vocabulary
* understanding the main idea
* identifying information from the text

2. ISTIMĀ' — LISTENING
======================

Add a dedicated listening activity connected to the same dialogue or short story.

Students should be able to listen to native-like Arabic pronunciation.

Add an audio player with:

* Play
* Pause
* Replay
* Progress bar
* Optional playback speed control

The audio should correspond exactly to the Arabic dialogue/text displayed on screen.

Before playing the audio, show:

"استمع جيدًا!"

"Listen carefully to the dialogue."

After listening, provide comprehension questions.

Example:

"ماذا يفعل الطالب يوم الاثنين؟"

Students choose the correct answer.

Create several listening question types:

* Multiple choice
* True/False
* Identify the word heard
* Match audio with the correct text
* Complete a missing word after listening

IMPORTANT:
The listening activity should not simply ask students to read the text.

Create a mode where the Arabic text can be temporarily hidden while the audio is playing so students practice listening comprehension.

3. KALĀM — SPEAKING
===================

Add an interactive speaking practice feature inspired by modern language-learning applications.

Create a section called:

"تدريب الكلام"
"Latihan Berbicara"

The speaking activity should contain several levels.

LEVEL 1 — LISTEN AND REPEAT

Show an Arabic sentence.

Example:

"ماذا تفعل يوم الاثنين؟"

Add a speaker button.

Student:

1. listens to the model pronunciation
2. presses the microphone button
3. repeats the sentence
4. stops recording
5. plays their recording back

UI:

🔊 Dengarkan
🎤 Rekam
▶ Putar Ulang
↻ Rekam Lagi
✓ Selesai

LEVEL 2 — READ AND SPEAK

Show an Arabic sentence without automatically playing the audio.

Students read the sentence aloud and record themselves.

LEVEL 3 — ANSWER THE QUESTION

Show a simple Arabic question.

Example:

"ماذا تفعل يوم الجمعة؟"

Students answer verbally.

Provide a microphone recording interface.

LEVEL 4 — ROLE PLAY

Create a short two-person dialogue.

The website plays Student A's line.

The student must respond by speaking Student B's line.

Example:

Website:
"ماذا تفعل يوم الاثنين؟"

Student:
"أذهب إلى المدرسة."

This creates a simple conversational simulation.

IMPORTANT SPEAKING FUNCTIONALITY:

Allow students to:

* start recording
* stop recording
* replay their recording
* delete and record again
* submit their recording

Use a large microphone button suitable for iPad touch interaction.

Show a recording timer.

Show a visual waveform or recording indicator while recording.

After submission, display encouraging feedback.

Do NOT give a numerical pronunciation score unless reliable speech-recognition functionality is actually available.

If speech recognition is not available, use recording + playback + teacher/researcher review instead.

5. INTEGRATED FOUR-SKILL MINI GAME
==================================

Expand the existing Joyful Learning section.

Instead of only having a vocabulary matching game, create several mini-game modes that integrate the four language skills.

GAME 1 — LISTEN AND MATCH

Play an Arabic audio recording.

Students choose the correct Arabic word or picture.

GAME 2 — READ AND MATCH

Students read an Arabic sentence and match it with the correct meaning/image.

GAME 3 — LISTEN AND ARRANGE

Play an Arabic sentence.

Students arrange the words into the correct order.

GAME 4 — SPEAKING CHALLENGE

Show a simple Arabic sentence.

Student presses the microphone and records themselves saying it.

Allow playback and retry.

GAME 5 — COMPLETE THE DIALOGUE

Show a dialogue with one missing line.

Play the first speaker's audio.

Students choose or speak the correct response.

Make the games short, playful, and appropriate for Grade 7 students.
