GLOBAL WORKFLOW RULES FOR THE ENTIRE WEBSITE:

Please apply these rules consistently to ALL pages and sections of the website, including Homepage, student information, avatar selection, Mindful Learning, Vocabulary, Istima’, Kalam, Kitabah, Mini Games, Evaluation, Reflection, and the final learning result page.

A. Every Page Change Starts from the Top
Whenever the user moves to a completely new page or section, automatically reset the scroll position to the very top of that page.

For example:
Homepage → Student Information
Student Information → Mindful Learning
Mindful Learning → Vocabulary
Vocabulary → Istima’
Istima’ → Kalam
Kalam → Kitabah
Kitabah → Mini Game
Mini Game → Evaluation
Evaluation → Reflection
Reflection → Learning Result

Every newly opened page must start at the top automatically. The user should never arrive in the middle or bottom of a new page.

B. Smart Auto-Scroll for Interactions
When an interaction reveals new content, activates a new button, or requires the user to continue somewhere else on the same page, automatically scroll to the relevant element.

Examples:
- After selecting an avatar → scroll to “Simpan & Lanjutkan”.
- After answering a question → scroll to “Lanjut”.
- After clicking “Lihat Contoh Kalimat” → scroll to the example sentence.
- After audio finishes → scroll to the Arabic text.
- After clicking translation → scroll to the translation.
- After clicking “Tekan untuk Rekam” → center the recording interaction area on the screen.
- After submitting a recording or written answer → automatically scroll to the “Lanjut” button.
- After completing a drawing → scroll to the completion message and next action.
- After completing any activity → guide the user to the next relevant button or section.

C. Center Important Interactive Areas
For interactive activities such as recording, writing, drawing, answering questions, or other exercises, automatically position the active interaction container comfortably in the center or main visible area of the screen whenever appropriate.

For example, when the user presses the recording button, the recording container should be clearly visible and centered instead of remaining partially hidden above or below the current viewport.

D. Smooth and Responsive Behavior
All automatic scrolling must be smooth, natural, and responsive.

It must work properly on:
- Desktop/laptop
- Mobile phones
- Tablets

Please ensure the automatic scrolling is not only working on desktop. Mobile and tablet compatibility is especially important.

E. Do Not Interrupt Normal Reading
Automatic scrolling should only happen when the user performs an interaction or moves to a new page. Do not continuously force-scroll while the user is manually reading or exploring content.

The goal is to create a guided and smooth learning experience where:
- New pages always begin from the top.
- Interactive actions automatically guide students to the next relevant content.
- Important buttons and newly revealed content are brought into view.
- Students do not need to repeatedly scroll manually just to continue the learning flow.

Please keep all existing content and functionality unchanged. Only improve and fix the navigation workflow, scroll behavior, and interaction focus across the entire website.
